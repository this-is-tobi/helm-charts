Homepage {{ .Chart.AppVersion }} is installed in namespace {{ .Release.Namespace }}.

Reach it from your machine:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "homepage.fullname" . }} 8080:{{ .Values.service.port }}

then browse http://localhost:8080.
{{- with include "homepage.allowedHosts" . }}

Homepage answers only to the hosts {{ . }} (and localhost): add the others it is reached at to `allowedHosts`.
{{- else }}

Homepage answers only to localhost until it is exposed: `ingress` and `httpRoute` allow their hosts
automatically, `allowedHosts` adds the hosts of routes created elsewhere.
{{- end }}
{{- if .Values.auth.enabled }}
{{- if and (not .Values.auth.oidc.enabled) (not .Values.auth.secret.existingSecret) }}

The password is in Secret {{ include "homepage.authSecretName" . }}, kept across upgrades:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "homepage.authSecretName" . }} -o jsonpath='{.data.{{ .Values.auth.secret.passwordKey }}}' | base64 -d

Tools that render the chart without cluster access (Argo CD) generate new ones on every render: give them an
existing Secret with `auth.secret.existingSecret`.
{{- end }}
{{- else }}

Authentication is off: Homepage serves its pages and APIs to whoever reaches it. Set `auth.enabled`, or keep it
behind a network or a proxy that authenticates.
{{- end }}
